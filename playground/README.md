# Playground

The component gallery: MDX docs with live, editable previews, a switcher across
all twelve themes, and a host-root-size control.

```bash
pnpm playground          # builds dist/, then serves on :5199
pnpm playground:build    # static build into playground/dist/
```

It imports from `../dist` through the same specifiers a consumer uses
(`@codellyson/justui/react`), so it exercises the published entry points rather
than the TS sources. That's why `playground` runs `build` first — after editing
`src/`, rerun the build (or keep `pnpm dev` running in another terminal).

Tailwind comes from `src/styles/tailwind.css` — the same stylesheet the package
ships as `@codellyson/justui/tailwind.css` — so the gallery is also the standing
test that its `@source` resolves.

## Adding a page

Drop an `.mdx` file in `src/docs/`. The filename is the route (`badge.mdx` →
`#badge`); two exports drive the sidebar:

```mdx
export const title = "Badge";
export const group = "Foundations";
```

Groups render in the order listed in `ORDER` in `src/App.tsx`; anything with an
unlisted group is dropped from the nav, so add it there first.

> **Restart after adding a file.** Tailwind's JIT registers the files that
> existed when the dev server booted. A brand-new `.mdx` renders, but classes
> that appear only in it won't be generated until you restart. Editing an
> existing file is fine.

## Live previews

A fence tagged `live` becomes an editable preview:

````markdown
```jsx live
<Button variant="secondary">Click me</Button>
```
````

The code is an expression. For anything needing hooks, add `noInline` and call
`render()`:

````markdown
```jsx live noInline
function Demo() {
  const [open, setOpen] = useState(false);
  return <Button onClick={() => setOpen(!open)}>{String(open)}</Button>;
}

render(<Demo />);
```
````

Everything exported from `@codellyson/justui/react` is in scope, plus `React`,
`useState`, `useEffect` and `useRef`. Fences without the `live` tag render as
plain code blocks.

Classes typed into a preview at runtime can't be generated by Tailwind — only
what's in the source files gets scanned. Stick to classes the library already
uses, or add yours to a `.mdx` file.

## Layout

`src/Live.tsx` renders each preview in a **block** container, not a flex row: a
flex item shrinks to min-content, which collapses `w-full` examples whose
children have no intrinsic width (skeletons, empty inputs). Examples bring their
own `flex`/`grid` wrapper when they need one.
