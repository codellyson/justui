# Avatar

A picture of a person or thing, with initials when there's no picture and no
layout shift while one loads.

```jsx live noInline
const face = (hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="96" height="96"><rect width="100%" height="100%" fill="hsl(${hue} 45% 45%)"/><circle cx="48" cy="38" r="16" fill="rgba(255,255,255,.85)"/><ellipse cx="48" cy="86" rx="28" ry="24" fill="rgba(255,255,255,.85)"/></svg>`
  )}`;

render(
  <div className="flex items-center gap-4">
    <Avatar src={face(210)} name="Ada Lovelace" />
    <Avatar name="Ada Lovelace" />
    <Avatar name="Grace" />
    <Avatar />
    <Avatar name="Ada Lovelace" radius="md" />
  </div>
);
```

Left to right: an image, initials from a two-word name, a single initial, an empty
placeholder, and `radius="md"` for a squared avatar. `name` does double duty —
initials *and* the image's `alt` — so a decorative avatar needs no extra prop.

A broken or slow `src` falls back to the initials rather than an empty box:

```jsx live
<div className="flex items-center gap-4">
  <Avatar src="https://example.invalid/nope.png" name="Ada Lovelace" />
  <Avatar src="https://example.invalid/nope.png" name="Bo Nguyen" fallback="?" />
</div>
```

## Sizes

```jsx live noInline
const face = (hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="96" height="96"><rect width="100%" height="100%" fill="hsl(${hue} 45% 45%)"/><circle cx="48" cy="38" r="16" fill="rgba(255,255,255,.85)"/><ellipse cx="48" cy="86" rx="28" ry="24" fill="rgba(255,255,255,.85)"/></svg>`
  )}`;

render(
  <div className="flex items-end gap-4">
    {['xs', 'sm', 'md', 'lg', 'xl'].map((size) => (
      <div key={size} className="flex flex-col items-center gap-2">
        <Avatar size={size} src={face(150)} name="Ada Lovelace" />
        <span className="font-mono text-[10px] text-muted">{size}</span>
      </div>
    ))}
  </div>
);
```

Initials scale with the box, so `xs` stays legible instead of overflowing.

## Groups

`AvatarGroup` overlaps its children and collapses the tail past `max`.

```jsx live noInline
const face = (hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="96" height="96"><rect width="100%" height="100%" fill="hsl(${hue} 45% 45%)"/><circle cx="48" cy="38" r="16" fill="rgba(255,255,255,.85)"/><ellipse cx="48" cy="86" rx="28" ry="24" fill="rgba(255,255,255,.85)"/></svg>`
  )}`;

const people = [
  { name: 'Ada Lovelace', hue: 210 },
  { name: 'Bo Nguyen', hue: 150 },
  { name: 'Cy Park', hue: 20 },
  { name: 'Di Alvarez', hue: 265 },
  { name: 'Eve Okafor', hue: 320 },
];

render(
  <div className="space-y-5">
    <AvatarGroup>
      {people.slice(0, 3).map((p) => (
        <Avatar key={p.name} src={face(p.hue)} name={p.name} />
      ))}
    </AvatarGroup>

    <AvatarGroup max={3}>
      {people.map((p) => (
        <Avatar key={p.name} src={face(p.hue)} name={p.name} />
      ))}
    </AvatarGroup>

    <AvatarGroup max={2} size="sm" spacing="sm">
      {people.map((p) => (
        <Avatar key={p.name} size="sm" name={p.name} />
      ))}
    </AvatarGroup>
  </div>
);
```

The overflow avatar reads `+N` and carries an `aria-label`. Pass the same `size`
to the group so it matches its children.

## With a presence badge

`WithBadge` positions a `Badge` on any child, so presence composes rather than
being another avatar prop. An empty `badge` with a squared-off `badgeClassName`
gives you a presence dot.

```jsx live noInline
const face = (hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="96" height="96"><rect width="100%" height="100%" fill="hsl(${hue} 45% 45%)"/><circle cx="48" cy="38" r="16" fill="rgba(255,255,255,.85)"/><ellipse cx="48" cy="86" rx="28" ry="24" fill="rgba(255,255,255,.85)"/></svg>`
  )}`;

render(
  <div className="flex items-center gap-6">
    <WithBadge badge="" color="green" position="bottom-right" badgeClassName="h-3 w-3 min-w-0 p-0">
      <Avatar src={face(150)} name="Ada Lovelace" />
    </WithBadge>
    <WithBadge badge="" color="gray" position="bottom-right" badgeClassName="h-3 w-3 min-w-0 p-0">
      <Avatar name="Bo Nguyen" />
    </WithBadge>
    <WithBadge badge="3" color="red">
      <Avatar name="Cy Park" radius="md" />
    </WithBadge>
  </div>
);
```

## Props

### Avatar

| Prop | Type | Default |
|---|---|---|
| `src` | `string` | — |
| `name` | `string` | — (initials + `alt`) |
| `alt` | `string` | `name` |
| `fallback` | `ReactNode` | initials from `name` |
| `size` | `xs` `sm` `md` `lg` `xl` | `md` |
| `radius` | `full` `md` | `full` |
| `delayMs` | `number` | — |

`delayMs` holds the fallback back briefly so a fast image doesn't flash initials
first.

### AvatarGroup

`max`, `size`, `spacing` (`sm` `md`), plus the native div props.
