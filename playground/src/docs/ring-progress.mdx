# RingProgress

`sections` stack around the ring, so a two-part ring is two entries rather than
two components.

```jsx live
<div className="flex flex-wrap items-center gap-8">
  <RingProgress sections={[{ value: 62, color: 'green' }]} label="62%" />
  <RingProgress
    size={140}
    thickness={16}
    roundCaps
    sections={[
      { value: 40, color: 'green' },
      { value: 25, color: 'orange' },
      { value: 15, color: 'red' },
    ]}
    label={<span className="text-xs text-muted">80%<br />used</span>}
  />
</div>
```

## Props

`RingProgress`: `sections` (`{ value, color }[]`), `size` (default `120`),
`thickness` (default `12`), `roundCaps`, `label`.

`color` on both is the shared palette: `primary` `gray` `red` `blue` `green`
`orange` `yellow`.
