# PinInput

One box per character, with paste, arrow keys and backspace-to-previous. The first
box carries `autocomplete="one-time-code"`, so iOS and Android offer the SMS code.

```jsx live noInline
function Demo() {
  const [code, setCode] = useState('');
  const [done, setDone] = useState(null);
  return (
    <div className="space-y-3">
      <PinInput length={6} value={code} onChange={setCode} onComplete={setDone} />
      <p className="text-xs text-muted">
        {code || '(empty)'}{done && ` · completed: ${done}`}
      </p>
    </div>
  );
}

render(<Demo />);
```

Paste a whole code into any box and it fills from there, moving focus to the end.
`onComplete` fires once every box is filled.

## Masked, alphanumeric, sizes

```jsx live noInline
function Demo() {
  const [a, setA] = useState('');
  const [b, setB] = useState('');
  return (
    <div className="space-y-5">
      <PinInput length={4} value={a} onChange={setA} mask size="lg" label="Masked, 4 digits" />
      <PinInput length={5} value={b} onChange={setB} alphanumeric size="sm"
        label="Alphanumeric" description="Letters are upper-cased." />
      <PinInput length={4} value="12" onChange={() => {}} error="That code has expired." />
      <PinInput length={4} value="99" onChange={() => {}} label="Disabled" disabled />
    </div>
  );
}

render(<Demo />);
```

## Props

| Prop | Type | Default |
|---|---|---|
| `length` | `number` | `6` |
| `value` | `string` | required |
| `onChange` | `(value: string) => void` | required |
| `onComplete` | `(value: string) => void` | — |
| `mask` | `boolean` | `false` |
| `alphanumeric` | `boolean` | `false` |
| `size` | `sm` `md` `lg` | `md` |
| `label` / `description` / `error` | `ReactNode` | — |
| `autoFocus` / `disabled` | `boolean` | `false` |

The group carries `role="group"` and each box an `aria-label` of its position, so a
screen reader announces "Digit 3 of 6" rather than six unlabelled fields.
