# Input

The control owns its own label, description and error — there's no separate
wrapper. The id is generated with `useId`, the label gets `htmlFor`, and
`aria-describedby` / `aria-invalid` are wired for you.

```jsx live
<div className="w-full max-w-sm space-y-4">
  <Input label="Workspace" placeholder="acme" description="Lowercase letters and dashes." />
  <Input label="Slug" defaultValue="Acme Corp" error="Must not contain spaces." />
  <Input label="Disabled" placeholder="Unavailable" disabled />
</div>
```

`error` supersedes `description` — pass both and only the error shows, and the
control picks up `aria-invalid` plus the danger border.

## onChange gives you the value

Not the event. Use `onChangeEvent` when you need the event itself.

```jsx live noInline
function Demo() {
  const [slug, setSlug] = useState('acme');
  const invalid = /\s/.test(slug);
  return (
    <div className="w-full max-w-sm space-y-2">
      <Input label="Slug" value={slug} onChange={setSlug} error={invalid && 'Must not contain spaces.'} />
      <p className="text-xs text-muted">value: <code>{slug || '(empty)'}</code></p>
    </div>
  );
}

render(<Demo />);
```

## Sizes

`size` maps to the same height as `Button` and `Select` — 28, 32, 36 and 44px —
so a field and a button line up in a row.

```jsx live
<div className="w-full max-w-sm space-y-3">
  <Input size="xs" placeholder="xs" />
  <Input size="sm" placeholder="sm" />
  <Input size="md" placeholder="md" />
  <Input size="lg" placeholder="lg" />
</div>
```

## Icons

`onLeftIconClick` / `onRightIconClick` make an icon interactive — it becomes a
real `<button>` rather than a decorative span, and it's `tabIndex={-1}` so tabbing
goes to the next field.

```jsx live
<div className="w-full max-w-sm space-y-3">
  <Input placeholder="Search" leftIcon={<MagnifyingGlassIcon />} />
  <Input placeholder="Larger icon" leftIcon={<MagnifyingGlassIcon />} iconSize="lg" />
  <Input placeholder="Clearable" defaultValue="something" rightIcon={<XMarkIcon />} onRightIconClick={() => {}} />
</div>
```

## type="number"

Steppers by default, clamped to `min`/`max`. Chrome's native spinners are
suppressed so there aren't two sets. `onChange` gives you a **number** here.

```jsx live noInline
function Demo() {
  const [qty, setQty] = useState(3);
  return (
    <div className="w-full max-w-sm space-y-4">
      <Input label="Quantity" type="number" value={qty} onChange={setQty} min={0} max={10} />
      <Input label="Step of 5" type="number" value={qty} onChange={setQty} step={5} />
      <Input label="No steppers" type="number" value={qty} onChange={setQty} showNumberControls={false} />
      <p className="text-xs text-muted">value: <code>{String(qty)}</code> ({typeof qty})</p>
    </div>
  );
}

render(<Demo />);
```

An empty field reports `NaN` — guard if that matters to you.

## type="password"

The reveal toggle is built in.

```jsx live
<div className="w-full max-w-sm space-y-4">
  <Input label="Password" type="password" defaultValue="hunter2" />
  <Input label="Without the toggle" type="password" defaultValue="hunter2" withPasswordToggle={false} />
</div>
```

## Props

`Input` narrows on `type`:

| | text family | `type="number"` |
|---|---|---|
| `value` | `string` | `number \| string` |
| `onChange` | `(value: string) => void` | `(value: number) => void` |
| extras | `withPasswordToggle` | `step`, `showNumberControls` |

The text family is `text` `email` `password` `url` `tel` `search`. Shared props:

| Prop | Type | Default |
|---|---|---|
| `label` / `description` / `error` | `ReactNode` | — |
| `size` | `xs` `sm` `md` `lg` | `md` |
| `leftIcon` / `rightIcon` | `ReactNode` | — |
| `onLeftIconClick` / `onRightIconClick` | `() => void` | — |
| `iconSize` | `sm` `md` `lg` | `sm` |
| `onChangeEvent` | `ChangeEventHandler` | — |
| `containerClassName` / `labelClassName` / `className` | `string` | — |

For money see [PriceInput](/price-input), for phone numbers
[PhoneInput](/phone-input), and for one-time codes [PinInput](/pin-input).
