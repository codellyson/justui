# Loader, Skeleton

Two ways to show work in progress: a spinner when you can't predict the shape of
what's coming, a skeleton when you can.

## Loader

```jsx live
<div className="flex items-end gap-6">
  {['xs', 'sm', 'md', 'lg', 'xl'].map((s) => (
    <div key={s} className="text-center">
      <Loader size={s} />
      <code className="mt-2 block font-mono text-xs text-muted">{s}</code>
    </div>
  ))}
</div>
```

```jsx live
<div className="flex items-center gap-6">
  <Loader color="accent" />
  <Loader color="primary" />
  <Loader color="danger" />
  <span className="text-accent"><Loader color="current" /></span>
</div>
```

`Loader` announces itself with `role="status"` and the text "Loading" by default.
Pass `label={null}` when something else already announces the wait — that's what
`Button loading` does, so the button isn't read out twice.

| Prop | Type | Default |
|---|---|---|
| `size` | `xs` `sm` `md` `lg` `xl` | `md` |
| `color` | `accent` `primary` `current` `danger` | `accent` |
| `label` | `string \| null` | `"Loading"` |

## Skeleton

Size it with utility classes — it has no intrinsic dimensions, so a bare
`<Skeleton />` renders nothing visible.

```jsx live
<div className="w-full max-w-sm space-y-3">
  <div className="flex items-center gap-3">
    <Skeleton className="h-10 w-10 rounded-full" />
    <div className="flex-1 space-y-2">
      <Skeleton className="h-3.5 w-1/2" />
      <Skeleton className="h-3 w-1/3" />
    </div>
  </div>
  <Skeleton className="h-24 w-full" />
  <div className="space-y-2">
    <Skeleton className="h-3 w-full" />
    <Skeleton className="h-3 w-5/6" />
    <Skeleton className="h-3 w-2/3" />
  </div>
</div>
```

### Match the real layout

Give the skeleton the same box the content will occupy, so nothing shifts when it
swaps in.

```jsx live noInline
function Demo() {
  const [loading, setLoading] = useState(true);
  return (
    <div className="w-full max-w-sm space-y-3">
      <Button size="xs" variant="outline" onClick={() => setLoading((v) => !v)}>
        {loading ? 'Show content' : 'Show skeleton'}
      </Button>
      {loading ? (
        <Skeleton className="h-9 w-full" />
      ) : (
        <div className="flex h-9 items-center rounded-md border border-border px-3 text-sm text-primary">
          acme-production
        </div>
      )}
    </div>
  );
}

render(<Demo />);
```

Add `aria-hidden="true"` when the surrounding region already announces its loading
state, so the placeholder isn't read out twice.
