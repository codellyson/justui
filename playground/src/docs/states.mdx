# EmptyState, LoadingOverlay, WithBadge, Blockquote

## EmptyState

Actions are data, not children — the layout of the button row is the component's
business.

```jsx live
<EmptyState
  icon={<span className="text-3xl">📦</span>}
  title="No projects yet"
  description="Create one to get a deploy URL, logs and a preview branch."
  primaryAction={{ label: 'Create project', onClick: () => {} }}
  secondaryAction={{ label: 'Import from Git', onClick: () => {} }}
/>
```

```jsx live
<Card withBorder className="w-full">
  <EmptyState title="No results" description="Try a different search term." />
</Card>
```

| Prop | Type |
|---|---|
| `title` | `ReactNode` |
| `description` | `ReactNode` |
| `icon` | `ReactNode` |
| `primaryAction` / `secondaryAction` | `{ label, onClick, variant?, leftIcon? }` |

## LoadingOverlay

Covers its nearest positioned ancestor, so the parent needs `relative`. It blocks
pointer events while visible — that's the point, it stops clicks landing on
controls that are mid-request.

```jsx live noInline
function Demo() {
  const [busy, setBusy] = useState(false);
  return (
    <div className="w-full max-w-sm space-y-3">
      <Button size="xs" variant="outline" onClick={() => setBusy((v) => !v)}>
        {busy ? 'Stop' : 'Start'}
      </Button>
      <div className="relative rounded-lg border border-border p-4">
        <LoadingOverlay visible={busy} loaderProps={{ size: 'sm' }} />
        <div className="space-y-2">
          <p className="text-sm text-primary">acme-production</p>
          <p className="text-sm text-secondary">Try clicking the button below while loading.</p>
          <Button size="xs">Can't click me</Button>
        </div>
      </div>
    </div>
  );
}

render(<Demo />);
```

| Prop | Type | Default |
|---|---|---|
| `visible` | `boolean` | required |
| `zIndex` | `number` | `40` |
| `loaderProps` | `{ size?, color?, label? }` | — |
| `overlayClassName` | `string` | — |

## WithBadge

Anchors a badge to a corner of whatever it wraps.

```jsx live
<div className="flex flex-wrap items-center gap-8">
  <WithBadge badge="9">
    <Button variant="outline">Inbox</Button>
  </WithBadge>
  <WithBadge badge="!" color="orange" position="top-left">
    <Button variant="outline">Alerts</Button>
  </WithBadge>
  <WithBadge badge="12" color="green" variant="light" position="bottom-right">
    <div className="flex h-10 w-10 items-center justify-center rounded-lg border border-border text-sm">A</div>
  </WithBadge>
  <WithBadge badge="0" hidden>
    <Button variant="outline">Nothing new</Button>
  </WithBadge>
</div>
```

`hidden` keeps the wrapper but drops the badge — for a zero count you don't want to
render but don't want to reflow either. Takes Badge's `variant`, `color` and
`size`, plus `position`.

## Blockquote

```jsx live
<div className="w-full max-w-lg space-y-4">
  <Blockquote>A plain pull quote.</Blockquote>
  <Blockquote variant="info" icon={<span>ℹ</span>}>Deploys are immutable.</Blockquote>
  <Blockquote variant="warning">This will drop the column.</Blockquote>
  <Blockquote variant="success" cite="Release notes 4.2">Migrations now run in a transaction.</Blockquote>
</div>
```

| Prop | Type | Default |
|---|---|---|
| `variant` | `default` `info` `warning` `success` | `default` |
| `icon` | `ReactNode` | — |
| `cite` | `ReactNode` | — |
