A grid of media tiles plus an add tile. Files arrive by click, drop or paste —
[react-dropzone](https://react-dropzone.js.org) handles that part. Reading the
files, uploading and compressing stay with you, so it works the same against any
backend.

**Try dropping an image onto the grid below.**

<Preview>
  <Demo0 client:visible />
</Preview>

```jsx
const shot = (label, hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="272" height="320"><rect width="100%" height="100%" fill="hsl(${hue} 40% 38%)"/><text x="50%" y="50%" fill="white" font-family="sans-serif" font-size="34" text-anchor="middle" dominant-baseline="middle">${label}</text></svg>`
  )}`;

function Demo() {
  const [items, setItems] = useState([
    { id: 1, url: shot('1', 210), alt: 'Front view' },
    { id: 2, url: shot('2', 150), alt: 'Side view' },
  ]);

  return (
    <div className="space-y-3">
      <AssetUploader
        items={items}
        maxItems={4}
        withRemaining
        onRemove={(id) => setItems((prev) => prev.filter((i) => i.id !== id))}
        onAddFiles={(files) =>
          setItems((prev) => [
            ...prev,
            ...files.map((file, i) => ({
              id: `${file.name}-${prev.length + i}`,
              url: URL.createObjectURL(file),
              alt: file.name,
            })),
          ])
        }
      />
      <p className="text-xs text-muted">{items.length} of 4 · pick a file to add one</p>
    </div>
  );
}
```

`onAddFiles` hands you a `File[]` however they arrived. While a drag is over the
grid it takes an accent ring and the add tile's label switches to "Drop to
upload". The add tile disappears once `maxItems` is reached, and dropping is
refused at that point too.

## Rejections

`accept`, `maxSize` and `minSize` are enforced before `onAddFiles` — anything
failing goes to `onReject` instead, with a per-file reason.

<Preview>
  <Demo1 client:visible />
</Preview>

```jsx
function Demo() {
  const [log, setLog] = useState([]);

  return (
    <div className="space-y-3">
      <AssetUploader
        onAddFiles={(files) => setLog(files.map((f) => `accepted ${f.name}`))}
        onReject={(rejections) =>
          setLog(
            rejections.map((r) => `${r.file.name} — ${r.errors.map((e) => e.code).join(', ')}`)
          )
        }
        accept={{ 'image/png': ['.png'] }}
        maxSize={50 * 1024}
        addLabel="PNG under 50 KB"
      />
      <div className="text-xs text-muted">
        {log.length === 0 ? 'Drop a JPEG or a large PNG to see a rejection.' : log.map((line, i) => <p key={i}>{line}</p>)}
      </div>
    </div>
  );
}
```

Error codes are `file-invalid-type`, `file-too-large`, `file-too-small` and
`too-many-files`.

## accept

`accept` takes react-dropzone's mime-to-extensions object — the native form, and
what `DEFAULT_ASSET_ACCEPT` is:

<Preview>
  <Demo2 client:visible />
</Preview>

```jsx
function Demo() {
  const [log, setLog] = useState('Drop something.');
  const shared = {
    onAddFiles: (files) => setLog(`accepted ${files.map((f) => f.name).join(', ')}`),
    onReject: (rs) => setLog(rs.map((r) => `${r.file.name} — ${r.errors[0].code}`).join(' · ')),
    multiple: true,
    maxItems: 9,
  };
  return (
    <div className="space-y-4">
      <AssetUploader
        {...shared}
        accept={{ 'image/*': [], 'application/pdf': ['.pdf'] }}
        addLabel="Object form"
      />
      <AssetUploader {...shared} accept="image/png,.heic" addLabel="String form" />
      <AssetUploader {...shared} accept=".csv,.tsv" addLabel="Extensions only" />
      <p className="text-xs text-muted">{log}</p>
    </div>
  );
}
```

A plain string works too, for call sites coming from elsewhere. It may mix MIME
types and bare extensions (`"image/png,.heic"`) or be extensions only
(`".csv,.tsv"`) — extensions are folded into the value position, since
react-dropzone requires its keys to be MIME types. `toAccept` is exported if you
want the same conversion yourself.

One trap worth knowing, inherited from react-dropzone: **giving a wildcard key
extensions narrows it rather than widening it.** `{ 'image/*': ['.heic'] }`
accepts `.heic` and *rejects* `image/png`, because the wildcard is dropped from
the accept attribute that matching uses. Write `{ 'image/*': [] }` for any image,
and list oddballs under their own key.

Drops are partially accepted: with room for two more files and four dropped, the
first two reach `onAddFiles` and the rest arrive at `onReject` as
`too-many-files`. Both callbacks fire for the same drop, so don't treat them as
mutually exclusive.

## Composing tiles

Upload UIs always grow per-tile affordances — progress while a file is in flight,
a retry on failure, a badge on the first image. Pass tiles as children instead of
`items` and each one takes its own overlay.

<Preview>
  <Demo3 client:visible />
</Preview>

```jsx
const shot = (label, hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="272" height="320"><rect width="100%" height="100%" fill="hsl(${hue} 40% 38%)"/><text x="50%" y="50%" fill="white" font-family="sans-serif" font-size="34" text-anchor="middle" dominant-baseline="middle">${label}</text></svg>`
  )}`;
```

Children render in order, so the add tile goes wherever you put it. `count` tells
the root how many tiles exist — it can't count children reliably — which is all
`withRemaining` and the auto-hide need.

`Add` also takes `children`, replacing the icon and label outright.

## Video tiles

A tile with `type="video"` gets a play badge. Nothing reads media metadata, so
pass `durationLabel` already formatted and `thumbnailUrl` for a poster frame —
without one the tile renders the `<video>` element itself.

  <Demo4 client:visible />
</Preview>

```jsx
const poster = (label, hue) =>

  )}`;
```

## Tile size

`orientation` picks between two presets. Past that, `tileWidth`, `tileHeight` and
`tileRatio` set real dimensions — a number is px, a string is any CSS length.

<Preview>
  <Demo5 client:visible />
</Preview>

```jsx
const shot = (hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="240" height="240"><rect width="100%" height="100%" fill="hsl(${hue} 40% 38%)"/></svg>`
  )}`;
```

The third row sets only `tileWidth` — the orientation's height survives, so a
tile never collapses because you set one axis.

### Ratios and fluid tiles

`tileRatio` replaces the height, so a tile can track its own width. Combine with
a percentage or `minmax` width for a grid that reflows.

<Preview>
  <Demo6 client:visible />
</Preview>

```jsx
const shot = (hue) =>
  `data:image/svg+xml,${encodeURIComponent(
    `<svg xmlns="http://www.w3.org/2000/svg" width="240" height="240"><rect width="100%" height="100%" fill="hsl(${hue} 40% 38%)"/></svg>`
  )}`;
```

## Props

### AssetUploader

| Prop | Type | Default |
|---|---|---|
| `onAddFiles` | `(files: File[]) => void` | required |
| `onReject` | `(rejections: FileRejection[]) => void` | — |
| `items` | `AssetUploaderItem[]` | — (use children) |
| `onRemove` | `(id: string \| number) => void` | — |
| `maxItems` | `number` | `5` |
| `count` | `number` | `items.length` |
| `maxSize` / `minSize` | `number` (bytes) | — |
| `orientation` | `portrait` `landscape` | `"portrait"` |
| `tileWidth` / `tileHeight` | `number \| string` | from `orientation` |
| `tileRatio` | `number` | — |
| `accept` | `string \| Accept` | `DEFAULT_ASSET_ACCEPT` |
| `multiple` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `noDrop` | `boolean` | `false` |
| `addLabel` / `withRemaining` | for the `items` shorthand | |
| `className` | `string` | — |
| `tileClassName` | `string` — escape hatch for looks, not size | — |

`AssetUploaderItem` is `{ id, url, type?, thumbnailUrl?, durationLabel?, alt? }`.

### AssetUploader.Item

`url`, `type`, `thumbnailUrl`, `durationLabel`, `alt`, `onRemove`, `children`,
`width`, `height`, `ratio`, `className`. The remove button only renders when
`onRemove` is given.

### AssetUploader.Add

`label`, `dropLabel`, `withRemaining`, `children`, `width`, `height`, `ratio`,
`className`. Renders nothing once `maxItems` is reached.

Sizes resolve per axis: a tile's own `width` / `height` / `ratio` beat the root's
`tileWidth` / `tileHeight` / `tileRatio`, which beat `orientation`. Setting one
axis leaves the other on its preset, and `ratio` replaces the height.

`alt` defaults to `"Preview"` — pass the filename or a description when you have
one, since the tile *is* the content rather than decoration.
