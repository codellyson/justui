Both take a 0–100 `value` and clamp out-of-range input rather than overflowing.

  <Demo0 client:visible />
</Preview>

```jsx
<div className="w-full max-w-sm space-y-4">
  <Progress value={28} />
  <Progress value={62} color="green" />
  <Progress value={90} color="orange" />
  <Progress value={100} color="red" />
</div>
```

## Sizes and stripes

<Preview>
  <Demo1 client:visible />
</Preview>

```jsx
<div className="w-full max-w-sm space-y-3">
  {['xs', 'sm', 'md', 'lg', 'xl'].map((s) => (
    <Progress key={s} value={55} size={s} />
  ))}
  <Progress value={70} size={24} striped animated color="green" />
</div>
```

`size` also takes a number for an exact pixel height. `striped` alone is static;
add `animated` to make the stripes travel.

## Accessible label

`Progress` is a `role="progressbar"` with `aria-valuenow`. Pass `label` to name it —
otherwise a screen reader announces a bare percentage with no context.

<Preview>
  <Demo2 client:visible />
</Preview>

```jsx
function Demo() {
  const [pct, setPct] = useState(35);
  return (
    <div className="w-full max-w-sm space-y-3">
      <Progress value={pct} label="Upload progress" color="green" />
      <Slider value={pct} onChange={setPct} label={(v) => `${v}%`} />
    </div>
  );
}
```

## Props

| Prop | Type | Default |
|---|---|---|
| `value` | `number` (0–100, clamped) | required |
| `color` | `primary` `gray` `red` `blue` `green` `orange` `yellow` | `primary` |
| `size` | `xs`–`xl` or a number of px | `md` |
| `striped` / `animated` | `boolean` | `false` |
| `label` | `string` | — |

`role="progressbar"` with `aria-valuenow`. Pass `label` to name it — otherwise a
screen reader announces a bare percentage with no context.
